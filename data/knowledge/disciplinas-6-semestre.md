# Disciplinas do 6º Semestre

## APS — Análise e Projeto de Sistemas
Carga: 75h. Sem pré-requisito. Análise estruturada e orientada a objetos, modelagem com UML completa (casos de uso, classes, sequência, atividades, estados, componentes, implantação), padrões de projeto avançados (Strategy, Observer, Adapter, Decorator), arquitetura em camadas, microserviços vs monolito, princípios SOLID. Voltado a estruturar grandes sistemas — útil para arquitetar projetos de IA escaláveis.

## DS IA — Desenvolvimento de Sistemas de IA
Carga: 75h. Sem pré-requisito. Como colocar IA em produção: serving de modelos com APIs REST/gRPC, MLOps básico (versionamento de modelos com MLflow, monitoramento, retreinamento), containerização com Docker, orquestração com Docker Compose e introdução a Kubernetes, A/B testing de modelos, feature stores, observabilidade (logs, métricas, alertas). Foco prático: pegar um modelo de ML e disponibilizá-lo como serviço escalável.

## PI II — Projeto Integrador II
Carga: 90h. Pré-req: PI I. Continuação do PI I, com escopo mais ambicioso e exigência maior em qualidade de entrega, documentação técnica e robustez do sistema. Costuma ser onde o aluno escolhe o problema do TCC.

## VD — Visualização de Dados
Carga: 75h. Sem pré-requisito. Princípios de design visual aplicados a dados (Tufte, Cleveland, Wilkinson), gramática dos gráficos (ggplot, plotnine), bibliotecas Python (Matplotlib, Seaborn, Plotly), dashboards interativos (Dash, Streamlit), storytelling com dados, escolha do gráfico certo para cada tipo de mensagem (comparação, distribuição, correlação, evolução temporal, parte-todo), visualização de redes e dados geoespaciais.
