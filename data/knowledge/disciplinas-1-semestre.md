# Disciplinas do 1º Semestre

## ALGA — Álgebra Linear e Geometria Analítica
Carga: 60h. Horário: Quarta 08:00–09:40 e 10:00–10:50.
Ementa: vetores no plano e no espaço, operações com vetores (soma, produto escalar, produto vetorial), retas e planos, sistemas de equações lineares, matrizes (operações, determinante, inversa), espaços vetoriais, transformações lineares, autovalores e autovetores. Conexão com Ciência de Dados: praticamente todo algoritmo de Machine Learning é matriz e vetor por baixo. Regressão linear é resolução de sistema linear via mínimos quadrados. PCA é decomposição em autovetores da matriz de covariância. Redes neurais são multiplicações de matrizes de pesos por vetores de entrada. Embeddings (como os usados em RAG) são vetores de alta dimensão num espaço vetorial. Bibliografia: Boldrini "Álgebra Linear", Anton "Álgebra Linear com Aplicações". Tópicos críticos para provas: cálculo de determinante, inversão de matriz por escalonamento, resolução de sistemas, diagonalização.

## BDI — Banco de Dados I
Carga: 60h. Horário: Sexta 08:00–09:40 e 10:00–10:50.
Ementa: introdução a banco de dados relacionais, modelo entidade-relacionamento (MER), normalização (1FN, 2FN, 3FN, BCNF), SQL básico (SELECT, INSERT, UPDATE, DELETE), cláusulas WHERE, ORDER BY, GROUP BY, HAVING, JOINs (INNER, LEFT, RIGHT, FULL), subconsultas, integridade referencial, chaves primárias e estrangeiras, transações ACID. Trabalho prático: modelagem e implementação de um banco de dados em PostgreSQL ou MySQL. Conexão com CD: SQL é a linguagem do dia-a-dia de qualquer cientista de dados. Saber escrever JOINs eficientes e entender índices economiza horas em análises. Bibliografia: Elmasri & Navathe "Sistemas de Banco de Dados", Date "Introdução a Sistemas de Banco de Dados". Avaliações típicas: P1 com modelagem ER + queries SQL básicas; P2 com normalização + queries complexas com múltiplos JOINs e subconsultas.

## BOOTI — Bootcamp I
Carga: 75h. Sem horário fixo (atividade intensiva).
Formato: bootcamp prático de imersão, geralmente concentrado em períodos específicos do semestre. Foco em integrar conhecimentos das outras disciplinas em um projeto guiado. Tipicamente envolve: definição de problema com dataset real, exploração inicial dos dados, formulação de hipóteses, primeira modelagem simples e apresentação. Avaliação por entregas e participação. Não tem prova clássica — a nota vem do projeto e da apresentação final.

## ES — Engenharia de Software
Carga: 60h. Horário: Terça 08:00–09:40 e 10:00–10:50.
Ementa: ciclo de vida de software, metodologias ágeis (Scrum, Kanban, XP), versus modelo cascata, levantamento e especificação de requisitos (funcionais e não funcionais), modelagem com UML (casos de uso, classes, sequência), padrões de projeto (Singleton, Factory, Observer, MVC), controle de versão com Git, testes (unitário, integração, sistema), integração contínua. Conexão com CD: Cientistas de Dados que sabem ES escrevem código mais limpo, modular e reproduzível, fazem code review, usam Git corretamente e entregam projetos sustentáveis. Bibliografia: Pressman "Engenharia de Software: uma Abordagem Profissional", Sommerville "Engenharia de Software". Avaliações: provas teóricas + projeto em grupo aplicando metodologia ágil.

## ICD — Introdução à Ciência de Dados
Carga: 60h. Horário: Quinta 08:00–09:40 e 10:00–10:50.
Ementa: o que é Ciência de Dados, papel do cientista de dados, pipeline CRISP-DM (entendimento do negócio, dos dados, preparação, modelagem, avaliação, implantação), introdução a Python para análise (Pandas, NumPy, Matplotlib), análise exploratória de dados (EDA), tipos de problemas (classificação, regressão, agrupamento), introdução a métricas, ética e LGPD aplicada a dados, panorama do mercado e ferramentas. Conexão prática: é a disciplina que dá o panorama. Tudo o que você verá nos próximos semestres é detalhamento do que ICD apresenta. Bibliografia: Provost & Fawcett "Data Science for Business", Grus "Data Science do Zero". Avaliações: provas + estudo de caso prático com dataset real, geralmente entregue como notebook Jupyter.

## LP — Lógica de Programação
Carga: 60h. Horário: Segunda 08:00–09:40 e 10:00–10:50.
Ementa: pensamento computacional, algoritmos, fluxogramas e pseudocódigo, variáveis e tipos primitivos, operadores aritméticos/lógicos/relacionais, estruturas condicionais (if/else, switch), estruturas de repetição (for, while, do-while), vetores e matrizes, funções e modularização, recursão (introdução), depuração. Geralmente usa Python como linguagem principal. Conexão com CD: é a base para tudo. Quem domina lógica resolve qualquer disciplina de programação depois. Bibliografia: Forbellone "Lógica de Programação", Deitel "Como Programar em Python". Avaliações: provas com exercícios de código + listas semanais. Pré-requisito de DCDI no 2º semestre — sem aprovar LP, não cursa DCDI.
