# Disciplinas do 5º Semestre

## APDL — Aprendizagem Profunda (Deep Learning)
Carga: 75h. Pré-req: AMML. Redes neurais artificiais (perceptron, MLP), funções de ativação (ReLU, sigmoid, tanh, softmax), backpropagation, otimizadores (SGD, Adam, RMSprop), regularização (dropout, batch norm), redes convolucionais (CNN) para visão computacional (LeNet, AlexNet, ResNet), redes recorrentes (RNN, LSTM, GRU), introdução a Transformers e atenção. Frameworks: PyTorch e/ou TensorFlow/Keras. Trabalho prático: treinar uma CNN para classificação de imagens e uma rede sequencial para texto.

## BD NoSQL (5º) — Banco de Dados NoSQL Avançado
Carga: 75h. Sem pré-requisito. Versão expandida do BDN do 3º semestre. Aprofunda em sharding, replicação, consistência eventual, agregação avançada em MongoDB, Redis (caching, pub/sub, estruturas de dados), Cassandra (modelagem orientada a query), bancos de grafos com Neo4j e Cypher, casos de uso reais (recomendação, redes sociais, IoT).

## BI (5º) — Business Intelligence Avançado
Carga: 75h. Sem pré-requisito. Continuação aprofundada de BI: BI self-service, governança de dados, certificação de métricas, integração com cloud (Azure Synapse, AWS QuickSight, GCP Looker Studio), automação de relatórios, comunicação executiva.

## PI I — Projeto Integrador I
Carga: 90h. Sem pré-requisito formal. Primeiro grande projeto interdisciplinar do curso. Os alunos trabalham em equipe sobre um problema real, definindo escopo, dataset, metodologia, executando o projeto e apresentando em banca. Integra conhecimentos de programação, banco de dados, BI, ML e visualização. Avaliação: entregas parciais + apresentação final em banca de professores.
