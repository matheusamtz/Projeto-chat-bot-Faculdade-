# Grade Curricular — Ciência de Dados e Machine Learning (CEUB)

## Visão geral
O curso tem 7 semestres (3,5 anos), com disciplinas organizadas em uma trilha que vai de fundamentos matemáticos e de programação até temas avançados como Deep Learning, Engenharia de Dados e Processamento de Linguagem Natural. Há quatro Bootcamps e três Projetos Integradores ao longo do curso, voltados à prática integrada.

## 1º Semestre
Disciplinas: Álgebra Linear e Geometria Analítica (ALGA, 60h), Banco de Dados I (BDI, 60h), Bootcamp I (BOOTI, 75h), Engenharia de Software (ES, 60h), Introdução à Ciência de Dados (ICD, 60h), Lógica de Programação (LP, 60h). Pré-requisitos: nenhum. Foco em fundamentos matemáticos, lógicos e introdução ao mundo da Ciência de Dados.

## 2º Semestre
Disciplinas: Banco de Dados II (BDII, 60h, pré-req: BDI), Business Intelligence I (BII, 60h), Cálculo para Computação (CC, 60h), Desenvolvimento para Ciência de Dados I (DCDI, 60h, pré-req: LP), Fundamentos de Segurança Cibernética (FSC, 60h). Aprofundamento em SQL avançado, primeiras técnicas de BI, cálculo aplicado e desenvolvimento em Python para dados.

## 3º Semestre
Disciplinas: Banco de Dados NoSQL (BDN, 60h, pré-req: BDI), Bootcamp II (BOOTII, 75h), Business Intelligence II (BIII, 60h, pré-req: BII), Desenvolvimento para Ciência de Dados II (DCDII, 60h, pré-req: DCDI), Estruturas para Ciência de Dados (ECD, 60h, pré-req: DCDI), Probabilidade e Estatística (PE, 60h). Início efetivo da modelagem estatística e de bancos não relacionais.

## 4º Semestre
Disciplinas: Aprendizagem de Máquina (AMML, 75h, pré-req: IA), Fundamentos de Big Data (FBD, 75h), Otimização Aplicada à Ciência de Dados (OACD, 75h), Recuperação da Informação (RI, 75h). Núcleo de Machine Learning começa formalmente. RI cobre busca textual, indexação invertida, TF-IDF, BM25 — base teórica para sistemas de busca e RAG.

## 5º Semestre
Disciplinas: Aprendizagem Profunda (APDL, 75h, pré-req: AMML), Banco de Dados NoSQL avançado (BD NoSQL, 75h), Business Intelligence (BI, 75h), Projeto Integrador I (PI I, 90h). Deep Learning com redes convolucionais, recorrentes e Transformers. PI I é o primeiro grande projeto interdisciplinar.

## 6º Semestre
Disciplinas: Análise e Projeto de Sistemas (APS, 75h), Desenvolvimento de Sistemas de IA (DS IA, 75h), Projeto Integrador II (PI II, 90h, pré-req: PI I), Visualização de Dados (VD, 75h). Construção de sistemas de IA em produção e técnicas modernas de visualização.

## 7º Semestre
Disciplinas: Engenharia de Dados (ED, 75h), Processamento de Linguagem Natural (PLN, 75h), Projeto Integrador III (PI III, 90h, pré-req: PI II), Segurança de Dados (SD, 75h). Pipelines de dados em produção, NLP avançado (incluindo embeddings, transformers, RAG), e aspectos de segurança e privacidade.

## Mapa de pré-requisitos
LP → DCDI → DCDII; LP → DCDI → ECD; BDI → BDII; BDI → BDN; BII → BIII; AMML → APDL; PI I → PI II → PI III. IA é pré-requisito de AMML (no 4º semestre). Disciplinas sem pré-requisito podem ser cursadas a qualquer momento que a grade permita, respeitando o semestre indicado como sugerido.

## Trilhas temáticas
Trilha de dados: BDI → BDII → BDN → ED. Trilha de programação: LP → DCDI → DCDII → ECD → DS IA. Trilha estatística/ML: PE → AMML → APDL → PLN. Trilha de produto: ICD → BII → BIII → BI → VD → PI I/II/III. Bootcamps (BOOTI, BOOTII) reforçam habilidades práticas multidisciplinares.
