# Disciplinas do 7º Semestre

## ED — Engenharia de Dados
Carga: 75h. Sem pré-requisito formal. Construção de pipelines de dados em produção: ingestão (batch e streaming), transformação (Spark, dbt), armazenamento (data lake, data warehouse, lakehouse), orquestração (Airflow, Prefect, Dagster), qualidade de dados (testes, monitoramento de drift, contratos de dados), modelagem dimensional revisitada com lentes modernas, ferramentas de cloud (Snowflake, Databricks, BigQuery, Redshift). É a disciplina que ensina a sustentar dados confiáveis para os modelos de ML rodarem em cima.

## PLN — Processamento de Linguagem Natural
Carga: 75h. Sem pré-requisito formal. Introdução ao NLP, pré-processamento textual (tokenização, stemming, lematização, POS tagging, NER), representações clássicas (bag of words, TF-IDF, n-grams), embeddings densos (Word2Vec, GloVe, FastText), modelos sequenciais (RNN, LSTM aplicadas a texto), Transformers (atenção, BERT, GPT), tarefas comuns (classificação de texto, análise de sentimento, NER, sumarização, tradução, perguntas e respostas, RAG), bibliotecas (NLTK, spaCy, Hugging Face Transformers). Disciplina diretamente relevante para construir o tipo de chatbot acadêmico que este sistema é.

## PI III — Projeto Integrador III
Carga: 90h. Pré-req: PI II. O TCC de fato. Projeto final do curso, com defesa em banca, documentação técnica completa, avaliação por métricas robustas. É aqui que o aluno demonstra autonomia plena para conduzir um projeto de Ciência de Dados do início ao fim.

## SD — Segurança de Dados
Carga: 75h. Sem pré-requisito formal. Anonimização e pseudonimização, k-anonimato, l-diversidade, t-closeness, privacidade diferencial, federated learning, homomorfismo, gestão de segredos, controle de acesso a dados sensíveis, cumprimento de LGPD/GDPR/HIPAA, auditoria, gestão de riscos, segurança em pipelines e modelos (data poisoning, model stealing, adversarial attacks).
