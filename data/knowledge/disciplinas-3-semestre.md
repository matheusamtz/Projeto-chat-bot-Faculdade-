# Disciplinas do 3º Semestre

## BDN — Banco de Dados NoSQL
Carga: 60h. Pré-req: BDI. Famílias de bancos NoSQL: chave-valor (Redis, DynamoDB), documentos (MongoDB, CouchDB), colunares (Cassandra, HBase) e grafos (Neo4j). Quando usar SQL vs NoSQL, teorema CAP (consistência, disponibilidade, tolerância a partição), modelagem em MongoDB (collections, documents, embedding vs referenciamento), queries em MongoDB com find, aggregate pipeline, índices. Trabalho prático: implementar um caso de uso em SQL e NoSQL e comparar trade-offs.

## BOOTII — Bootcamp II
Carga: 75h. Sem horário fixo. Bootcamp prático com escopo maior que o BOOTI, geralmente envolvendo um problema com dados reais e ciclo completo de pipeline. Avaliação por entregas e apresentação. Conecta DCDI/DCDII com fundamentos de banco e BI.

## BIII — Business Intelligence II
Carga: 60h. Pré-req: BII. Aprofunda BI: storytelling com dados, design de dashboards (princípios de Tufte, escolha de gráfico certo para cada métrica), DAX em Power BI (medidas calculadas, contexto de filtro), modelagem semântica avançada, performance de modelos, automação de pipelines de dados para BI, integração com bancos de dados e APIs. Projeto: dashboard executivo com métricas em tempo real.

## DCDII — Desenvolvimento para Ciência de Dados II
Carga: 60h. Pré-req: DCDI. Continuação aprofundada de Python para dados: APIs REST com Flask/FastAPI para servir modelos, manipulação avançada com Pandas, programação orientada a objetos aplicada a pipelines de dados, testes unitários com pytest, logging, tratamento de exceções, web scraping com BeautifulSoup e Selenium, automação de tarefas, introdução a containerização com Docker. Avaliação: projeto final implementando um pipeline completo.

## ECD — Estruturas para Ciência de Dados
Carga: 60h. Pré-req: DCDI. Estruturas de dados clássicas com viés para CD: arrays, listas ligadas, pilhas, filas, hash tables, árvores binárias e de busca, heaps, grafos, complexidade assintótica (Big O), algoritmos de ordenação (merge sort, quick sort), algoritmos de busca (busca binária, BFS, DFS), algoritmos em grafos (Dijkstra, Kruskal). Por que importa em CD: implementações eficientes de operações em datasets grandes dependem de estruturas certas. Hash tables são base de groupby em Pandas.

## PE — Probabilidade e Estatística
Carga: 60h. Sem pré-requisito formal. Probabilidade (espaço amostral, eventos, axiomas, condicional, Bayes), variáveis aleatórias (discretas e contínuas), distribuições (Bernoulli, binomial, Poisson, normal, exponencial, t, qui-quadrado), estatística descritiva (média, mediana, moda, variância, desvio padrão, quartis), inferência estatística (estimação pontual e intervalar, teste de hipóteses, p-valor, valor crítico), correlação e regressão linear simples, ANOVA. Conexão com ML: teste estatístico é base para validar diferenças entre modelos; distribuições normais aparecem em hipóteses de muitos algoritmos; Bayes é a base de Naive Bayes e de modelos probabilísticos.
